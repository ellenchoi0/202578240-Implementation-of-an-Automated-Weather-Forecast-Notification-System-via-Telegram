# Implementation of an Automated Weather Forecast Notification System via Telegram

라즈베리파이와 Python을 활용하여 기상청 RSS 데이터를 수집하고, 가공된 기상 정보를 텔레그램 메시지로 자동 전송하는 IoT 알리미 시스템 구축 프로젝트입니다.

> 본 프로젝트는 'requests'와 'telepot' 라이브러리를 통해 외부 서버와의 데이터 통신을 구현하며,
> 비동기 처리(async/await) 및 리스트 컴프리헨션을 통한 코드 최적화 메커니즘을 심층적으로 다룹니다.

## 개요

라즈베리파이의 네트워크 인터페이스를 통해 기상청 XML 데이터를 스크래핑하고, 사용자 친화적인 포맷으로 가공하여 전송합니다. 웹 스크래핑과 크롤링의 차이점을 이해하고, 비동기 프로그래밍 구조를 통해 서버-클라이언트 간의 효율적인 데이터 송수신 원리를 학습합니다.

## 핵심 특징

- **실시간 웹 스크래핑**: 기상청 RSS 피드에서 시간, 기온, 습도, 날씨 데이터를 정밀하게 추출
- **데이터 최적화 가공**: 정규표현식(re) 및 리스트 컴프리헨션을 활용한 효율적인 데이터 파싱 및 가독성 확보
- **자동 알림 시스템**: telepot 라이브러리를 이용한 특정 시간대(예: 오전 7시부터 3시간 간격) 자동 전송 로직 구현
- **비동기 처리 구조**: async와 await 키워드를 활용한 논블로킹(Non-blocking) 방식의 리소스 관리

## 시스템 아키텍처

본 프로젝트는 기상청 서버(RSS), 라즈베리파이(Controller), 텔레그램 API(Messenger) 간의 상호작용으로 설계되었습니다.

## 주요 이론

- **스크래핑 vs 크롤링**: 특정 주소에서 필요한 정보만 정밀하게 추출하는 스크래핑 기술 활용
- **비동기 프로그래밍**: await를 통한 대기 시간 중 자원 양보 및 프로세스 실행 효율 극대화
- **데이터 구조**: 키-값 쌍의 JSON/XML 구조와 파이썬 딕셔너리 자료형의 호환성 이해

## 실행 및 설치

### 1. 의존성 설치

본 프로젝트는 다음과 같은 라이브러리 설치가 필요합니다.
> pip install requests telepot

### 2. 프로그램 실행

Thonny IDE를 실행하거나 터미널에서 다음 명령어를 입력합니다. (파일명: main28-2.py)
> python3 main28-2.py

### 3. 설정 사항
- 텔레그램 Bot Token과 Chat ID를 소스 코드 내 해당 변수에 설정해야 합니다.
- 기상청 RSS URL의 zone 코드를 통해 원하는 지역을 설정할 수 있습니다.

## 주요 이슈 해결
- 전송 로직의 신뢰성: 초 단위 일치 방식(if hms == "HH:MM:SS")의 전송 누락 위험을 방지하기 위해, 향후 시간 범위 기반 체크 또는 전송 완료 플래그 도입의 필요성을 확인함.
- 코드 가독성 및 속도: 단순 for 루프를 리스트 컴프리헨션으로 전환하여 파이썬 인터프리터 수준에서 연산 속도를 최적화하고 가독성을 높임.
- 데이터 파싱 고도화: 정규표현식(re)의 한계를 극복하기 위해, 계층적 구조 분석에 유리한 BeautifulSoup 라이브러리 활용 방안을 검토하여 유지보수성 향상 기틀 마련.
- IoT 서비스 실증: 단순 정보 조회를 넘어 라즈베리파이가 네트워크 데이터를 스스로 판단하여 사용자에게 전달하는 능동적인 IoT 서비스 기초 역량을 확보함.
